# Umbrella Intelligence

Internal intelligence foundation for a portfolio of revenue-producing projects.

## Core purpose
Stop circular research. Every project, research finding, failure and success should improve future decisions.

## Decision protocol
1. Retrieve existing intelligence
2. Identify gaps
3. Research missing evidence
4. Store findings and lessons
5. Update the decision

## Persistent memory
`data/memory.json` is the durable project-memory layer. It is separate from temporary inbox notes and is intended to preserve project process, decisions, experiments, results, unresolved questions and lessons that should survive across conversations.

For every major project, memory should answer:
- Why did we start?
- What did we believe?
- What did we build or test?
- What actually happened?
- What did we learn?
- What remains unresolved?
- What should happen next?
- What assets or evidence were created?

The assistant should retrieve relevant memory before continuing project work and write back validated, durable learning after meaningful changes or tests. Contradictory new evidence should update the existing record rather than silently creating competing truths.
